## Programmatic access

Get the current jurisdiction list and status via the API:

```bash
# All jurisdictions with active status
curl https://api.bizverify.co/v1/jurisdictions

# Full config including jurisdiction details
curl https://api.bizverify.co/v1/config
```

These endpoints are unauthenticated — no API key required.
